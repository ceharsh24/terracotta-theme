Java-Specific Notes

Java-specific semantic scopes are now in place

Terracotta now gives Java its own structural lanes instead of treating everything like generic TextMate fallback. Primitive types use the type lane (#E090B0), annotations use a separate clay accent (#DC9C7C italic), and this/super return to the terracotta keyword family.

Literals are cleaner than the older audit showed

String: "Terracotta" #DBAC3B
Number: 3.14159265 #D4A068
Constant: MAX_CAPACITY #BCA060

The three lanes are still warm, but they no longer collapse into one amber band. That keeps Java constant-heavy code readable without breaking the theme’s earthy character.

The remaining tradeoff is warm keyword density

Java still produces dense terracotta runs in declarations like public static final, especially compared with JavaScript or Python. That is now softened by purple primitive types and sandy operators, but the language still reads warmer than average by design.

Current: public static final int MAX = 1024;

What works especially well

Functions (#52C4A8) stay lively without looking neon. Inherited types (#C89080 italic) separate cleanly from declared classes. Built-in constants (null/false) are easy to spot, and the cooler comment/doc-comment pair gives Javadoc enough structure to scan quickly.
