Cross-Theme Summary & Contrast Ratios

01
Number / Constant: Collision Resolved
All themes now separate numbers from user constants using a distinct literal lane. Dark: #DCA068 vs #C4A468. Dark Dimmed: #D4A068 vs #BCA060. Light: #8A3050 vs #685020. Light Bright: #882E4C vs #705818. The light themes in particular keep numerics warm, but no longer let them collapse into the old operator/property palette.
02
HTML Tag / Keyword: Separation Added
Light themes keep HTML and JSX tags in their own clay-rose lane: #984848 in Light and #984040 in Light Bright, distinct from keywords #9A3016 and #9C3418. In React-heavy code, component names stay readable without blending into control flow.
03
Variable / Property: Semantic Lanes
Dark themes split variables (bright warm sand #CABFA6) from properties (olive-clay #A8A060). Dark Dimmed uses #C2B89A / #B4A468. This warm-on-warm separation preserves Terracotta's identity while keeping member access easy to scan.
04
WCAG AA Contrast: All Themes Pass
All documented syntax tokens meet WCAG AA (4.5:1) against their backgrounds. Comments are the lowest-contrast token at 4.9–7.0:1, keywords range 5.3–9.0:1, functions 7.4–8.3:1, and strings 5.9–13.8:1. High Contrast CB still achieves AAA across the board.
05
Python Decorators: Effective Across All Variants
Python decorators use their own rose-to-plum accent across the standard themes (for example #D8907A in Dark and #985840 in Light), so annotations stay visually distinct from both types and functions without needing all-day italics.
06
Light Bright: Halation Fix Applied
Light Bright now pairs a softened editor foreground #1E1E1E with a warm near-white background #FDFCFA. The brighter canvas makes the variant clearly distinct from Light, while the darker line highlight and cooler structural accents keep it usable for long daytime sessions.
