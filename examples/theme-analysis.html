The light variants now separate warm class names from cooler interface/generic lanes and keep self/this in ochre. Light uses #593F73 / #2F63A4 / #7A6726; Light Bright uses #3C4A86 / #3266AD / #7A6724. This keeps TypeScript, Java, and Python object-heavy code from collapsing into one warm family.

All documented syntax tokens meet WCAG AA (4.5:1) against their backgrounds. Comments now range 4.9–7.0:1, keywords 5.1–9.0:1, functions 7.1–8.3:1, and strings 5.1–13.8:1. High Contrast CB still achieves AAA across the board.
05
Secondary Warm Roles Reduced
The light themes now avoid stacking extra near-terracotta lanes. Parameters collapse into the cocoa identifier lane #5B4030 / #4A3528, while decorators keep their own plum-rose lane #7A4764 / #7E4870. Dense signatures read cleaner without losing emphasis.
06
Light Bright: Distinct Identity Restored
Light Bright now pairs a mineral background #FCFBF7 with cooler structure and type lanes #3A5A6C / #3C4A86 / #3266AD, while Light stays warmer with parchment surfaces at #F4EEE4. The two light themes read as different tools instead of brightness variants of the same palette.
